‹ 回到寶寶日記

寶寶日記的資料存在你自己的 Google 試算表，不會經過別人。照下面做完，就能對 Siri 說「寶寶紀錄」來記錄，打開 App 看圖表；另一半的手機也能一起記、一起看。

💻 第 1～4 步用電腦（要貼程式），第 5～7 步用 iPhone。準備：一個 Google 帳號（Gmail 就是）。

1建立試算表 💻 電腦

  1. 用電腦的 Chrome 打開 📗 sheets.new（沒登入會先要你登入 Google）
    一份空白的「未命名的試算表」
  2. 點左上角「未命名的試算表」這幾個字，改成 寶寶日記，按 Enter

2貼上程式 💻 電腦

  1. 試算表上方選單點 擴充功能 → Apps Script
    開了一個新分頁，左邊有「Code.gs」，中間寫著 function myFunction() { }
  2. 左上角「未命名的專案」點一下，改名為 寶寶日記 → 重新命名
  3. 點一下中間的程式區，按 Ctrl＋A（Mac 是 ⌘＋A）全選，按 Delete 刪光
  4. 回到這一頁按 ，再回 Apps Script 按 Ctrl＋V 貼上
    很長一段程式，第一段是「寶寶日記 — Google Apps Script 後端」
  5. 設定密碼：找到這一行（大約第 13 行）
    const KEY = '請改成你的密碼';
    把引號裡的字改成你自己的密碼，英文和數字就好，例如 const KEY = 'bb2026xyz';
    ⚠️ 引號 ' 和最後的分號 ; 要留著。這組密碼等一下 App 和捷徑都要用，先記下來。
  6. 按上方的 💾（儲存專案），或按 Ctrl＋S

3第一次執行（授權） 💻 電腦

  1. 上方工具列「▷ 執行」右邊有個下拉選單，選 setup
  2. 按 ▷ 執行
    「需要授權」視窗 → 按 審查權限
  3. 選你的 Google 帳號
  4. 出現「Google 尚未驗證這個應用程式」：點左下角小字 進階 → 最下面 前往「寶寶日記」（不安全）
    這是你自己剛貼的程式，只會讀寫你這份試算表，所以可以放心。
  5. 按 允許（有勾選框的話全部勾起來再按「繼續」）
    下方「執行記錄」出現「完成！」；回到試算表，下面多了「紀錄」「設定」「自訂說法」三個分頁

4部署成網址 💻 電腦

  1. Apps Script 右上角藍色 部署 → 新增部署作業
  2. 左邊「選取類型」旁的 ⚙️ 齒輪 → 網頁應用程式
  3. 右邊設定：
    ・說明：隨便寫，例如「寶寶日記」
    ・執行身分：我（你的信箱）
    ・具有存取權的使用者：所有人
    一定要選「所有人」，不然 Siri 和另一半的手機連不進來。別人沒有密碼也讀不到資料。
  4. 按 部署（如果又要授權，照第 3 步再按一次允許）
  5. 出現「網頁應用程式」網址，按下面的 複製
    網址長這樣：https://script.google.com/macros/s/很長一串/exec，結尾是 /exec
  6. 檢查一下：把網址貼到瀏覽器新分頁打開
    「寶寶日記後端正常運作（第 2 版）」就成功了
  7. 把網址和密碼傳到自己的 iPhone（例如用 LINE 傳給自己、或「Keep 備忘錄」）

5把 App 裝到 iPhone 主畫面 📱 iPhone

  1. 用 iPhone 相機掃這個 QR code（或在 iPhone 的 Safari 打開上面的 App 連結）
    要用 Safari 打開。
    如果是用 LINE 點開的，點右下角「⋯」→「用 Safari 開啟」。
  2. Safari 下方中間的 分享（方框加向上箭頭）→ 往下滑 → 加入主畫面 → 右上 加入
    主畫面多一個寶寶臉圖示「寶寶日記」
  3. 從主畫面打開寶寶日記 → 下方 ⚙️ 設定
  4. 「網頁應用程式網址」貼上第 4 步的網址；「密碼」打第 2 步設的密碼；「我是」選 媽媽 或 爸爸
  5. 按 儲存並測試連線
    「✓ 連線成功」
  6. 同一頁上面填寶寶名字和生日 → 儲存（兩支手機都會看到）

6做 Siri 捷徑 📱 iPhone

⭐ 最簡單：在寶寶日記 App →「⚙️ 設定」→「🎙 Siri 語音設定」→「📋 看捷徑做法」。那裡的步驟已經帶入你的網址和密碼，每一格都有「複製」按鈕，照著點就好。也可以在那裡改呼叫的名稱、加「換尿布」這種一句話捷徑、設定「ㄋㄟㄋㄟ」這種家裡的說法。

如果要照這裡做（名稱用「寶寶紀錄」）：

  1. 打開 iPhone 的「捷徑」App（藍紫色兩個方塊的圖示）🔷 打開捷徑，下方選「捷徑」→ 右上角 ＋
  2. 點最上面的「新捷徑」→ 重新命名 → 輸入 寶寶紀錄 → 完成
    這個名字就是呼叫 Siri 的說法：「嘿 Siri，寶寶紀錄」。想改成別的名字也可以，例如「小寶日記」。
  3. 點 搜尋動作 → 輸入「聽寫」→ 點 聽寫文字；點這個動作右邊的 ⌄：語言選 中文（台灣）、停止聆聽選 暫停後
  4. 下方搜尋列輸入「URL」→ 點 取得 URL 內容；點藍色的「URL」字樣 → 貼上第 4 步的網址
  5. 點這個動作右邊的 ⌄ 展開：方法 改 POST；要求本文 選 JSON
  6. 點 新增新欄位 → 文字：「鍵」打 key，「文字」打你的密碼
  7. 再 新增新欄位 → 文字：「鍵」打 text，「文字」那格點一下 → 鍵盤上方選藍色變數 聽寫的文字
  8. 再 新增新欄位 → 文字：「鍵」打 plain，「文字」打 1
  9. （可省略）再加一個：「鍵」by，「文字」媽媽（App 會顯示是誰記的）
  10. 下方搜尋列輸入「說出」→ 點 說出文字（內容自動是「URL 的內容」）
  11. 右上角 完成。試試看：說「嘿 Siri，寶寶紀錄」，聽到嗶聲說「喝奶一百二」
    Siri 唸「已記錄喝奶 120cc。今天第 1 次，共 120cc」
  12. 第一次用會問「要允許「寶寶紀錄」傳送到 script.google.com 嗎？」→ 選 永遠允許（可能會問兩次）

7另一半的手機 📱 iPhone

  1. 把 App 連結、同一組網址和密碼傳給另一半
  2. 另一半照第 5 步裝 App，「我是」選自己 → 儲存並測試連線
  3. Siri 捷徑：照第 6 步做一個；或在 App「🎙 Siri 語音設定」照步驟做（「by」改成自己）
👨‍👩‍👧 兩支手機寫進的是同一份試算表。App 打開時、以及每 1 分鐘會自動更新，對方剛記的很快就看得到。

🛠 有問題時

App 顯示「密碼不對」／Siri 說「沒有記錄成功：密碼不對」

App 設定、捷徑裡的 key、Code.gs 第一行的 KEY，三個要一模一樣（大小寫也要一樣）。改了 Code.gs 的密碼，要照下面「更新程式」重新部署才生效。

App 顯示「回應看不懂，網址可能貼錯了」

網址要是第 4 步「網頁應用程式」那個，結尾是 /exec，不是 Apps Script 編輯器的網址。第 4 步的「具有存取權的使用者」要選「所有人」。

Siri 說「寶寶紀錄」打不開，或跑去搜尋網路

捷徑名稱要和說的一字不差；名字太常見可能被 Siri 當成別的指令，換成「小寶日記」這種特別一點的名稱。

Siri 聽錯字

到 App「🎙 Siri 語音設定 → 試試看」打一樣的字看會記成什麼；把常被聽錯的字加到「自訂說法」。

找不到部署網址了

打開 我的 Apps Script 專案 → 寶寶日記 → 部署 → 管理部署作業，網址在右邊。

更新程式（有新版本時）

Apps Script 裡全選刪掉 → 貼上新的程式碼 → 把密碼改回你原本的 → 儲存 → 部署 → 管理部署作業 → ✏️ 編輯 → 版本選 新版本 → 部署。網址不會變，手機不用重設。
