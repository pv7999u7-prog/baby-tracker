設定教學
大約 10 分鐘，只要做一次
‹ 回到寶寶日記

寶寶日記的資料會存在你自己的 Google 試算表，不會經過別人。做完下面 6 步，就可以用 Siri 說「寶寶紀錄」來記錄，打開 App 也能看到圖表。

💻 第 1～4 步要貼程式，用電腦做最快。第 5、6 步用 iPhone 做。

1建立試算表 電腦

  1. 用自己的 Google 帳號打開 sheets.new，會開一份新的試算表
  2. 左上角把名稱改成「寶寶日記」

2貼上程式 電腦

  1. 上方選單：擴充功能 → Apps Script
  2. 把編輯區原本的幾行全部刪掉
  3. 按下面的按鈕複製程式，貼進編輯區
    或直接打開程式碼全選複製
  4. 改密碼：第一個 const KEY = '請改成你的密碼'; 把引號裡的字改成你自己的密碼（英文或數字，例如 bb2026xyz）
  5. 按 💾 儲存

3第一次執行（授權） 電腦

  1. 上方工具列函式選單選 setup，按 ▷ 執行
  2. 跳出「需要授權」→ 選自己的帳號
  3. 如果看到「Google 尚未驗證這個應用程式」：按 進階 → 前往「未命名的專案」（不安全） → 允許
    這是你自己剛貼的程式，只會讀寫這一份試算表，所以可以放心允許。
  4. 回到試算表，會多出「紀錄」和「設定」兩個分頁

4部署成網址 電腦

  1. Apps Script 右上角 部署 → 新增部署作業
  2. 點「選取類型」旁的 ⚙️ → 網頁應用程式
  3. 執行身分：我；誰可以存取：所有人
  4. 按 部署，複製「網頁應用程式網址」（https://script.google.com/macros/s/…/exec）
  5. 把網址和密碼傳到自己的 iPhone（例如用 LINE 傳給自己）
之後如果程式有更新：部署 → 管理部署作業 → ✏️ → 版本選「新版本」→ 部署。這樣網址不會變。

5把 App 加到主畫面 iPhone

  1. 用 Safari 打開寶寶日記網址
  2. 下方 分享 按鈕 → 加入主畫面
  3. 從主畫面打開 → 設定 → 貼上網址和密碼 → 選「我是媽媽／爸爸」→ 儲存並測試連線
  4. 在設定頁填寶寶名字和生日，兩支手機都會看到
👨‍👩‍👧 另一半的手機：一樣做第 5、6 步，填同一組網址和密碼就好，兩個人的紀錄會在一起。

6做 Siri 捷徑 iPhone

打開「捷徑」App → 右上 ＋ → 最上面名稱改成 寶寶紀錄，依序加入 3 個動作：

① 聽寫文字搜尋「聽寫」。點開箭頭：語言選「中文（台灣）」，停止聆聽選「暫停後」。
② 取得 URL 內容 URL：貼上第 4 步的網址
點開箭頭 → 方法：POST；要求本文：JSON，新增 3 個欄位（都選「文字」）：
・key → 你的密碼
・text → 點一下，選上面的變數「聽寫的文字」
・plain → 1
（想知道誰記的，可再加 by → 媽媽）
③ 說出文字搜尋「說出」，內容選上一步的「URL 的內容」。

完成！對 iPhone 說：「嘿 Siri，寶寶紀錄」，聽到「嗶」之後說「喝奶一百二」，Siri 會回答「已記錄喝奶 120cc。今天第 5 次，共 600cc…」。

⚡ 想更快：複製這個捷徑，把 ① 換成「文字」動作直接寫「尿布」，名稱改成「換尿布」。之後說「嘿 Siri，換尿布」一句就記好。「寶寶睡了」（文字：睡覺）、「寶寶醒了」（文字：起床）也很好用。
📤 要給另一半：在捷徑上長按 → 分享 → 用 LINE 傳過去，對方再把 by 改成自己。
